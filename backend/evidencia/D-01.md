# D-01 — Imagen base y tamaño

Fecha: 2026-11-08  
Host: VPS de EasyPanel (`root@srv1930369`)  
Objetivo: demostrar que la base es `python:3.12-alpine`, que pesa menos de 100 MB y que la imagen del proyecto existe.

## Comando

```bash
docker images --format 'table {{.Repository}}:{{.Tag}}\t{{.ID}}\t{{.Size}}' | grep -E 'python|libreria-api'
```

## Salida real

```text
python:3.12-alpine                                   e064671ca452   74.8MB
easypanel/grupo-acgs/libreria-api:latest             9e0cc33cc883   255MB
```

## Lectura

- La base `python:3.12-alpine` mide **74.8 MB**, por debajo del límite de 100 MB.
- La imagen construida por EasyPanel es `easypanel/grupo-acgs/libreria-api:latest` (255 MB).
- `docker pull python:3.12-alpine` ya se había ejecutado y devolvió el digest
  `sha256:e064671ca452259bab50e8e2c7bd896e39e9a343bb06ca25234adf6fe18d0fc7`.
