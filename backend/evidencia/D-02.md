# D-02 — Build y ejecución healthy con migraciones aplicadas

Fecha: 2026-11-08  
Host: VPS de EasyPanel (`root@srv1930369`)  
Objetivo: demostrar que la imagen construida desde `despliegue/` arranca, aplica
Alembic y queda healthy. Runtime: EasyPanel, app `grupo-acgs/libreria-api`,
contenedor localizado por nombre `libreria-api`, puerto 8000.

## Comandos

```bash
CID=$(docker ps --filter name=libreria-api --filter status=running -q | head -n1)
docker inspect "$CID" --format '{{.State.Status}} | {{if .State.Health}}{{.State.Health.Status}}{{end}}'
docker exec "$CID" python -m alembic current
```

## Salida real

```text
running | healthy
5f67a857f685 (head)
```

## Lectura

El contenedor está `running` y `healthy`; la base está en la cabeza de Alembic
(`5f67a857f685`). El build de EasyPanel usa el `Dockerfile` de `despliegue/` y
el `CMD` ejecuta `alembic upgrade head` antes de `uvicorn main:app`.
