# D-05 — Sin variables obligatorias el contenedor no queda sirviendo

Fecha: 2026-11-08  
Host: VPS de EasyPanel (`root@srv1930369`)  
Objetivo: demostrar que la aplicación falla al arrancar si faltan las cinco
variables `POSTGRES_*`.

## Comando

```bash
docker run --rm --name libreria-d05 easypanel/grupo-acgs/libreria-api:latest
echo "EXIT=$?"
```

## Salida real (resumida)

```text
pydantic_core._pydantic_core.ValidationError: 5 validation errors for Settings
POSTGRES_USER
  Field required
POSTGRES_PASSWORD
  Field required
POSTGRES_DB
  Field required
POSTGRES_HOST
  Field required
POSTGRES_PORT
  Field required
EXIT=1
```

## Lectura

El contenedor termina con código **1** y no queda `Up`. No hay valores por
defecto para las variables obligatorias, así que un despliegue sin `--env-file`
(o sin la configuración de EasyPanel) no sirve.

El comando usa `--rm`: el contenedor se elimina al terminar, así que la prueba
es `EXIT=1`, no una fila en `docker ps -a`. Si se quiere ver el estado
terminado, repetir sin `--rm`; no se dejó ningún contenedor de prueba.
