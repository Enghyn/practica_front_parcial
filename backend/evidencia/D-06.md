# D-06 — La imagen no contiene `.env` ni secretos

Fecha: 2026-11-08  
Host: VPS de EasyPanel (`root@srv1930369`)  
Objetivo: comprobar que el contexto de build excluye `.env`, `.venv`, `.git` y
`__pycache__`, y que la imagen no trae variables de base ni contraseñas.

## 1. Variables dentro de la imagen, sin `--env-file`

```bash
docker run --rm --entrypoint env easypanel/grupo-acgs/libreria-api:latest \
  | grep -Ei 'POSTGRES|DATABASE' || echo 'sin variables de BD en la imagen'
```

Salida real:

```text
sin variables de BD en la imagen
```

No aparece `POSTGRES_PASSWORD`, `POSTGRES_USER`, `POSTGRES_DB`, `POSTGRES_HOST`,
`POSTGRES_PORT` ni `DATABASE_URL`.

## 2. Archivos en `/app`

```bash
CID=$(docker ps --filter name=libreria-api --filter status=running -q | head -n1)
docker exec "$CID" sh -lc 'ls -a /app | grep -E "^\.env" || echo "sin .env en /app"'
```

Salida real:

```text
sin .env en /app
```

El listado de `/app` no incluye `.env`, `.env.*`, `.venv`, `.git` ni
`__pycache__`; el `.dockerignore` los excluye.

## Lectura

La imagen es autocontenida y no incorpora secretos. Las variables `POSTGRES_*`
se inyectan recién al correr el contenedor con `--env-file` o desde EasyPanel.
