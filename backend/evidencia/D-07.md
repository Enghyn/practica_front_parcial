# D-07 — El contenedor corre con usuario no root

Fecha: 2026-11-08  
Host: VPS de EasyPanel (`root@srv1930369`)  
Objetivo: comprobar que el proceso no corre como `root`.

## Comando

```bash
CID=$(docker ps --filter name=libreria-api --filter status=running -q | head -n1)
docker exec "$CID" id
```

## Salida real

```text
uid=100(app) gid=101(app) groups=101(app)
```

## Lectura

El usuario efectivo es `app` (`uid=100`), distinto de `root` (`uid=0`). El
`Dockerfile` crea el usuario `app`, ajusta el dueño de `/app` y ejecuta con
`USER app`.
