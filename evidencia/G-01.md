# G-01 · Catálogo

**Fecha**: 2026-11-10
**Entorno**: frontend servido en `http://127.0.0.1:8080` con `dev_server.py`, proxying a la API
desplegada. Capturas en `G-01-catalogo-1440.png` y `G-01-catalogo-390.png`.

## Pasos y resultado observado

| Paso | Acción | Resultado observado |
|---|---|---|
| 1 | Abrir `/` | Se listan los libros de la primera página. Resumen: `Mostrando 1–6`. Botones «Página anterior» y «Página siguiente» deshabilitados porque hay una sola página. |
| 2 | Buscar `ray` | Una tarjeta: **Rayuela**. Resumen: `Mostrando 1–1 para «ray»`. La búsqueda no distingue mayúsculas. |
| 3 | Buscar `zzzz` | Se muestra «No se encontraron libros que coincidan con la búsqueda» y no el mensaje de catálogo vacío. |
| 4 | Limpiar la búsqueda | Vuelve a `Mostrando 1–6`. |
| 5 | Pulsar «Ver autores» en Rayuela | Se consulta `GET /libros/1` y se muestra `Julio Cortázar — autor`. Un segundo clic alterna el panel sin repetir la petición (caché de sesión). |
| 6 | Verificar el género de «El jardín de senderos que se bifurcan» | Muestra **Sin clasificar** porque `genero_id` es nulo. |
| 7 | Redimensionar a 390x844 | Sin desborde horizontal (`scrollWidth` 375 ≤ 390). Las tablas se desplazan dentro de su contenedor. |

## Verificación técnica

```
GET /api/libros/?limit=20&offset=0          -> 200, array de 6 libros
GET /api/libros/?limit=20&offset=0&titulo=ray -> 200, 1 libro
GET /api/libros/1                          -> 200, autores[0].autor_nombre = "Julio Cortázar"
```

Precio, editorial y género se toman de `editorial.nombre` y `genero.nombre` del listado; los autores
sólo se consultan al abrir el detalle, como pide la consigna.

- `G-01-catalogo-390.png`: catálogo y resto de la página a 390x844.
