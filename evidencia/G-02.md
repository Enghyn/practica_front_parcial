# G-02 · Alta de libro

**Fecha**: 2026-11-10
**Entorno**: frontend local con proxy a la API desplegada. Captura: `G-02-409-isbn.png`.

## Datos ficticios usados

| Campo | Valor |
|---|---|
| Título | El jardín de senderos que se bifurcan |
| ISBN | `978-GLOBAL-0001-X` |
| Precio | 12345.50 |
| Stock | 7 |
| Editorial | 1 (Sudamericana) |
| Género | sin clasificar |
| Autoría | autor 1, rol `coautor`, orden 1 |

## Pasos y resultado observado

| Paso | Acción | Resultado observado |
|---|---|---|
| 1 | Cargar autoría con ID 1 y pulsar «Verificar y agregar» | Se consulta `GET /autores/1`, se muestra **Julio Cortázar** y la fila queda con rol y orden. |
| 2 | Completar el formulario y enviar | `POST /libros/` responde **201**. Mensaje: `Libro registrado con el identificador 6.` El formulario se limpia, las autorías se vacían y el catálogo pasa a 6 libros. |
| 3 | Consultar el detalle | `GET /libros/6` devuelve el libro con `stock: 7` y la autoría `coautor` orden 1. |
| 4 | Repetir el ISBN `978-GLOBAL-0001-X` con una autoría válida | `POST /libros/` responde **409**. La interfaz muestra el mensaje del servidor y conserva el título y la autoría cargados; el botón vuelve a estar habilitado. |
| 5 | Verificar el género nulo | La tarjeta del libro nuevo muestra **Sin clasificar**. |

## Cuerpo enviado

```json
{
  "isbn": "978-GLOBAL-0001-X",
  "titulo": "El jardín de senderos que se bifurcan",
  "precio": 12345.5,
  "stock": 7,
  "editorial_id": 1,
  "genero_id": null,
  "autores": [{ "autor_id": 1, "rol": "coautor", "orden": 1 }]
}
```

## Observación sobre el mensaje de 409

El backend de los capítulos 1 a 4 devuelve `{"detail": "No se pudo crear el libro (datos inválidos)"}`
para el ISBN duplicado. La interfaz muestra ese texto, tal como pide la consigna («mostrá el mensaje
del servidor ante un 409 o 422»). El backend del parcial completo devuelve un mensaje más específico,
pero no forma parte de esta entrega.
