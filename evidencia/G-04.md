# G-04 · Venta e historial

**Fecha**: 2026-11-10
**Entorno**: frontend local con proxy a la API desplegada. Captura: `G-04-detalle-venta.png`.

## Venta registrada

| Campo | Valor |
|---|---|
| Cliente | 3 — Cliente Global Ficticio |
| Renglón 1 | libro 1 (Rayuela), cantidad 2, precio unitario `25000.00` |
| Renglón 2 | libro 4 (Respiración artificial), cantidad 1, precio unitario `27000.00` |
| Total devuelto por la API | `77000.00` |
| Identificador | 5 |

## Pasos y resultado observado

| Paso | Acción | Resultado observado |
|---|---|---|
| 1 | Elegir el cliente 3 y agregar el libro 1 con cantidad 2 | El renglón aparece con subtotal `$ 50000.00`. El total de la venta se actualiza. |
| 2 | Agregar el libro 4 con cantidad 1 | Segundo renglón con subtotal `$ 27000.00`. Total: `$ 77000.00`. |
| 3 | Intentar agregar otra vez el libro 1 | Se rechaza: «Ese libro ya tiene un renglón en la venta; modificá su cantidad en la tabla.» La tabla sigue con 2 renglones. |
| 4 | Pulsar «Confirmar venta» | El botón se deshabilita y muestra «Confirmando…». `POST /ventas/` responde **201**. Mensaje: `Venta 5 confirmada por $ 77000.00.` El formulario se limpia (0 renglones, cliente vacío, total `$ 0.00`). |
| 5 | Verificar el historial | Se recarga la primera página y la venta 5 aparece con fecha, cliente y `$ 77000.00`. |
| 6 | Recargar la página y abrir el detalle | `GET /ventas/5` devuelve los dos renglones con `precio_unitario` y `subtotal` históricos. El resumen muestra `Detalle de la venta 5 — Cliente Global Ficticio — 8/11/2026, 05:26:19`. |

## Cuerpo enviado

```json
{
  "cliente_id": 3,
  "renglones": [
    { "libro_id": 1, "cantidad": 2 },
    { "libro_id": 4, "cantidad": 1 }
  ]
}
```

Sólo esos campos: el servidor calcula el total y copia el precio unitario. La interfaz muestra los
importes de la respuesta, no los calculados localmente.
