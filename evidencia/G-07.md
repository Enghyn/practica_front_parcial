# G-07 · Despliegue

**Fecha**: 2026-11-10
**Estado**: pendiente de la publicación del servicio `frontend` en Easypanel.

## Qué debe demostrar

1. La imagen del frontend se construye a partir de `frontend/Dockerfile`.
2. La URL pública abre por HTTPS.
3. `/api/health/ready` responde 200 a través del proxy del frontend.
4. Los datos siguen disponibles después de un redespliegue.

## Verificación previa (ya ejecutada en local)

| Control | Resultado |
|---|---|
| `frontend/Dockerfile` presente con `nginx:1.30-alpine`, dos `COPY` y `EXPOSE 80` | OK |
| `frontend/.dockerignore` excluye `.git`, `.env`, `node_modules` y `.DS_Store` | OK |
| `frontend/default.conf.template` con `proxy_pass http://${API_UPSTREAM}/;` | OK |
| Proxy equivalente con `dev_server.py` | `/api/health/ready` → 200; `/api/libros/` → array |
| Build local con Docker | **no ejecutado**: no hay Docker instalado en la máquina de desarrollo; se valida en el build de Easypanel |

## Comandos para completar el caso

```powershell
# 1) salud a través del dominio público del frontend
Invoke-RestMethod https://<dominio>/api/health/ready

# 2) sitio por HTTPS
Invoke-WebRequest https://<dominio>/ -UseBasicParsing | Select-Object StatusCode

# 3) catálogo con datos
Invoke-RestMethod "https://<dominio>/api/libros/?limit=2&offset=0"

# 4) persistencia: anotar la cantidad de ventas, redesplegar el frontend y repetir
(Invoke-RestMethod "https://<dominio>/api/ventas/?limit=100&offset=0").Count
```

## Diagnóstico si falla

| Síntoma | Revisar |
|---|---|
| Falla un `COPY` | Build path `frontend/`, `Dockerfile`, `default.conf.template` y `public/` |
| Nginx no arranca | `API_UPSTREAM` ausente o con `http://` o barra final |
| `/api/` devuelve 502 | Nombre interno del backend y que el servicio esté corriendo |
| 404 en la API | Prefijo `/api` y barra final de la ruta |
